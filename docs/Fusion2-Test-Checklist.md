# Fusion 2 — 미검증 항목 테스트 체크리스트 (Pass B + 4-G)

> 이번 세션에 추가/수정된 항목의 검증 절차. 모두 **추가형(컴파일 비파괴)**이며 Pass A(실 InGameScene
> 네트워크 전환)는 이미 검증됨. ParrelSync 2피어(원본=Host, 클론=Client) 또는 Multiplayer Play Mode로 진행.
> 각 항목: **준비 → 절차 → 기대결과 → 실패 시 의심점**.

## 0. 사전 준비 (한 번만)

1. **Pass B 배선**: InGameScene 열고 메뉴 `Tools ▸ Homebody Monster ▸ Fusion ▸ Wire Open Scene for Pass B (HUD + Cinemachine)` 실행 → Console에 각 단계 ✅ 확인 → **Ctrl+S 저장**.
2. **덫 프리팹 배선(선택)**: `Tools ▸ … ▸ Create NetPlayer & Wire (1-A)` 1회 재실행 → NetPlayer.prefab에 TrapPrefab 배선(안 해도 덫은 즉발 AoE로 폴백).
3. **테스트 계정**: 부활 테스트용으로 부활권 보유 계정 사용(wg235/qwt1324에 3장 지급됨). 피자는 4계정 100개씩 지급됨(리롤용).

## 1. ⭐ 컴파일 클린 (제일 먼저)

이번 세션에 12개 파일을 추가/수정했으므로 **이게 1순위**.

- **절차**: Unity로 포커스 전환 → 자동 컴파일 대기 → Console `Clear` → 빨간 에러 0개 확인.
- **기대결과**: 에러 0. 경고는 무방.
- **실패 시**: 에러의 파일/줄 번호를 그대로 전달. (신규: NetTrap, NetHudBridge, NetCinemachineTarget, FusionInGameCutover / 수정: NetPlayer, NetStatus, NetSkillSystem, NetProjectile, NetHUD, NetMobileInput, NetMatch, NetFx, FusionPoCSceneSetup)

## 2. Pass B — 캔버스 HUD (InGameHUD 구동)

- **준비**: 0번 완료. 2피어 로그인 → 매칭 → InGameScene 진입.
- **절차/기대결과**:
  - [ ] **체력바**: 내 HP 표시, 피격 시 즉시 감소 반영
  - [ ] **생존자 수**: "생존자 N/총원" 실제값
  - [ ] **타이머**: 카운트다운(120초 → 감소). 0 도달 시 최고 HP 생존자 승리
  - [ ] **스킬 버튼**: 내가 굴린 직업의 스킬 **한글 이름** 표시, 사용 시 쿨다운 fill 차오름 + 버튼 일시 비활성
  - [ ] **스킬 버튼 탭/클릭 → 발동**(조이스틱 방향으로 조준). 버튼 누를 때 캐릭터가 이동/공격으로 새지 않음
  - [ ] **킬피드**: "공격자 → 피격자", 내가 공격자면 노란색 강조
  - [ ] **중복 없음**: 좌하단 OnGUI 임시 체력바/스킬 줄이 더 이상 안 보임(캔버스로 대체)
  - [ ] **VariableJoystick 에러 사라짐**(Pass B 메뉴가 레거시 조이스틱 비활성화)
- **실패 시 의심**:
  - 캔버스가 안 뜸 → InGameHUD 캔버스 비활성/InGameHUD 컴포넌트 없음(메뉴 로그 확인)
  - 스킬 버튼 안 뜸 → InGameHUD의 `skillButtons/skillNameTexts/skillCooldownFills` 배열 미배선
  - OnGUI와 캔버스가 **둘 다** 보임 → NetHudBridge가 씬에 없음(메뉴 미실행) → `NetHudBridge.Active=false`

## 3. Pass B — Cinemachine 카메라

- **준비**: 0번 완료(vcam 활성 + NetCinemachineTarget 부착, NetCameraFollow/NGO CameraFollow 비활성).
- **절차/기대결과**:
  - [ ] 카메라가 **내 캐릭터를 부드럽게 추적**
  - [ ] 아레나 경계에서 바깥 허공이 과도하게 보이지 않음(Cinemachine 구도 설정에 의존)
  - [ ] **사망 시 관전**: 생존자에게 카메라 이동, **Tab**으로 대상 순환
- **실패 시 의심**:
  - 카메라 안 움직임 → vcam 비활성 그대로 / NetCinemachineTarget 미부착 / NetCameraFollow가 아직 활성(충돌)
  - 메뉴 로그에 `CinemachineCamera를 찾지 못했습니다` → 카메라 리그 구성 공유 필요

## 4. Pass B — 부활/포기 (캔버스 이관)

- **준비**: 부활권 보유 계정. 매치 시작 **60초 이내**, 본인 외 생존자 **1명 이상**.
- **절차/기대결과**:
  - [ ] 사망 시 **캔버스 revivePanel** 표시(OnGUI 부활창 아님)
  - [ ] 카운트다운 타이머 동작, 보유 부활권/매치 잔여 안내
  - [ ] **"부활권 사용"** → "부활 처리 중…" → 만피 부활(킬 유지), 무한 대기 없음
  - [ ] **"포기"** → 사망 확정 + 관전
  - [ ] DB: profiles.revive_ticket_count 차감(검증은 DB 직접 확인 요청 가능)
- **실패 시 의심**: 패널 안 뜸 → revivePanel 미배선 / 부활 조건 미충족(60s 경과·생존자 부족·기회 소진). 무한 "처리 중" → Supabase 연결(INACTIVE면 복구 필요)

## 5. Pass B — 항복(Surrender, Esc/Android Back)

- **준비**: 생존 중(준비시간 아님).
- **절차/기대결과**:
  - [ ] **Esc** → surrenderConfirmPanel 표시, 다시 **Esc** → 닫힘(토글)
  - [ ] **확인** → 자진 사망(부활 제안 없음) → 관전. 매치는 다른 생존자 위해 계속
  - [ ] **취소** → 닫힘, 계속 플레이
  - [ ] (Android 빌드) 하드웨어 백 키도 동일 — **기기에서 별도 확인**(에디터는 Esc)
- **실패 시 의심**: 패널 안 뜸 → surrenderConfirmPanel/버튼 미배선

## 6. 4-G — 스킬 8종 본래 메커니즘

> ⚠️ **캐릭터는 매칭 시 랜덤 롤**이라 특정 스킬을 받으려면 해당 직업이 나와야 함.
> **매칭 후 15초 준비(리롤) 윈도우**에 직업/스킬을 확인하고, 원하는 직업이 아니면 **🍕20 리롤**(테스트 계정 피자 100). 2피어 중 한쪽을 "맞아주는 더미"로 두면 관찰 쉬움.

- [ ] **신의 가호**(성기사 DivineGrace): 시전 후 **다음 1회 피격 완전 무효**(데미지 0), 그 다음 타격부터 정상
- [ ] **얼음 방패**(마법사 IceShield): 시전 **2.5초 무적**(피해 0) + 이동/공격 불가(버튼 비활성) + 머리 위 🧊
- [ ] **불굴의 분노**(광전사 UndyingRage): 6초간 적 타격 시 **HP 흡수**(체력 회복) + 가하는 피해↑ + 받는 피해↑ + 🔥
- [ ] **수호천사**(성직자 GuardianAngel): 버프 중 치명상 시 **즉사 대신 30% HP로 1회 생존** + 😇
- [ ] **무자비**(광전사 RuthlessStrike): 강한 근접 피해 + **자기 HP 12% 자해**(자신에게 데미지 팝업)
- [ ] **관통화살**(궁수 PierceArrow): 화살이 첫 적에 안 멈추고 **여러 명 관통**(적 2명 이상 일렬 배치로 확인)
- [ ] **간식타임**(셰프 SnackTime): 회복 + **슬로우/스턴/독/낙인 즉시 해제**(디버프 걸린 상태에서 사용)
- [ ] **덫**(궁수 Trap): 조준 지점에 **붉은 반투명 덫** 설치 → 적이 밟으면 데미지+슬로우 후 소멸 (TrapPrefab 배선 시; 미배선이면 즉발 AoE)
- **회귀 확인**: 면역(얼음방패) 아닌 평상시엔 슬로우/스턴/독이 **정상 적용**되는지(면역 가드 추가 영향 없음)

# 추가 버그수정 배치 검증 (B 이후 누적분)

> ⚠️ **전제: Pass C가 끝나서 프로젝트가 컴파일되는 상태여야 테스트 가능.** 현재는 Pass C 진행 중이라
> 컴파일이 안 됩니다(NGO 로비 클러스터 정리 전). **Pass C 완료(아래 P항목) 후** 이 배치를 검증하세요.

## A. 준비/배선 (한 번)
1. InGameScene 열고 메뉴 `Tools ▸ Homebody Monster ▸ Fusion ▸ Wire Open Scene for Pass B` **재실행**
   → 이번엔 **NetHUD**(준비창/머리위바/글리프) + **NetArenaBounds**(아레나 경계, 스폰포인트로 추정)도 생성됨 → **Ctrl+S**.
2. (덫 쓰려면) `Create NetPlayer & Wire (1-A)` 1회 재실행(TrapPrefab 배선).

## B. ⭐ NetArenaBounds 사이징 (수동 — 벽 통과 버그의 핵심)
- Fusion 이동은 물리 콜라이더가 아니라 **NetArena.Clamp(코드)**로 막힘 → 경계가 실제 벽과 맞아야 함.
- **절차(게임 실행 불필요, Scene 뷰에서)**:
  1. Hierarchy에서 **NetArenaBounds** 선택.
  2. Scene 뷰에 **노란 사각형**(플레이 영역) + **주황 사각형**(벽 포함)이 보임([ExecuteAlways]).
  3. Inspector의 `center` / `half Width` / `half Height`를 조정해 **노란 사각형을 벽 이미지 안쪽 가장자리**에 정확히 맞춤.
     - center = 아레나 중심 월드좌표(아레나가 원점이 아니면 보정).
     - halfWidth/halfHeight = 중심에서 벽 안쪽까지 거리(유닛).
  4. Ctrl+S.
- 애매하면 **벽 네 모서리의 월드좌표(또는 Scene 뷰 스샷)**를 주면 값을 계산해 줌.

## C. 검증 항목 (2피어, Login부터)
- [ ] **C-1 준비시간 이동 잠금**: 매치 진입 직후 15초 준비창 동안 조이스틱/WASD로 이동 시도 → **캐릭터 정지(안 움직임)**, 타이머 **02:00 고정**. 리롤 버튼은 동작. 15초 후 → 이동 가능 + 타이머 카운트다운 시작.
- [ ] **C-2 상대 체력 숨김**: 두 캐릭터가 한 화면에 보이게 한 뒤 머리 위 확인 → **내 체력바만 보임**, 상대는 **닉네임만**(체력바 X). (상태 글리프는 양쪽 다 표시 — 의도)
- [ ] **C-3 벽 통과 해결**: 캐릭터를 사방 벽으로 밀어붙임 → **벽 안쪽 가장자리에서 멈춤**(배경/물 영역으로 안 나감). 투사체도 벽 근처서 소멸. (실패 시 B의 NetArenaBounds 값 재조정)
- [ ] **C-4 리롤 후 스킬 라벨 갱신**: 피자 ≥20 계정으로 준비 15초 동안 🍕20 리롤 → 직업 바뀜 → **스킬 버튼 라벨이 새 직업 스킬로 즉시 갱신**(이전 직업 스킬명 잔존 X), "내 캐릭터: XXX" 직업명도 갱신.
- [ ] **C-5 타이머/배너 회귀**: 타이머가 준비 후 02:00→카운트다운, **재시작 시 결과 배너가 사라지고** 새 게임 정상 진행.
- [ ] **C-6 준비창/머리위 UI**: 준비 15초 "⏳ 준비 시간 N초" + 🍕리롤 버튼 표시, 머리 위 닉네임 + 상태 글리프(🧊⚡❄☣🛡🔰🔥✨😇) 표시.

# P. Pass C 검증 (NGO 제거 후 — 가장 중요)

> Pass C로 NGO 코드를 대거 제거/수정했으므로, **컴파일 + 회귀**가 1순위.

- [ ] **P-1 컴파일 클린**: Console 에러 0. (Pass C 전체 완료 후. 미완료면 NGO 로비 클러스터 관련 에러 잔존)
- [ ] **P-2 전체 플로우**: 로그인 → 매칭 → InGameScene → 매치 진행 → 결과 저장(DB) → 로비 복귀, 전 구간 정상.
- [ ] **P-3 전투 회귀**: 평타/40스킬/상태이상/투사체/데미지 — SkillSystem(쿨다운만 남김)·CombatSystem(TryTenacity/GuardianAngel 제거)·StatusEffectSystem(삭제)·GameData(DamageResult) 변경이 Fusion 경로에 영향 없는지.
- [ ] **P-4 로비 채팅/Presence**: (AppNetworkManager EDIT=A 방식 적용 시) 로비 채팅·접속자 목록 동작.
- [ ] **P-5 missing-script 정리 확인**: 씬에서 삭제된 NGO 스크립트 자리(NetworkManager/NetworkSpawnManager 등 비활성 오브젝트)에 missing-script 경고 → 해당 오브젝트 삭제됐는지.
